# Instruções para agentes de IA neste repositório

Antes de editar qualquer arquivo, fazer deploy na VPS, ou mexer em
cron/systemd deste projeto, leia [ATIVIDADE.md](ATIVIDADE.md) — é o
registro de "quem está mexendo em quê agora", usado pra evitar colisão
entre sessões de IA diferentes trabalhando ao mesmo tempo neste mesmo
repositório (já aconteceu duas vezes num único dia). Anote lá o que você
vai mexer antes de começar, e apague quando terminar.

Para o resto do contexto do projeto (arquitetura, histórico, pendências),
veja [CLAUDE.md](CLAUDE.md) — vale como referência geral independente de
qual ferramenta de IA está sendo usada.
